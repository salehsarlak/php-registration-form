## 🌈 About The Project

A clean, modern and fully responsive **Registration Form** built with pure **PHP** and **CSS**.

This project features both **client-side** (HTML5) and **server-side** (PHP) validation to provide a smooth and secure user experience.

Perfect for beginners who want to learn form handling, validation and modern UI design.

---

## ✨ Features

<div align="center">

| Feature | Description |
|:-------:|:------------|
| 🎨 | Beautiful modern UI with Poppins font |

## 🚀 How to Run Locally

### Prerequisites
- XAMPP / WAMP / Laragon **or** PHP built-in server

### Steps

1. **Clone the repository**

```bash
git clone https://github.com/salehsarlak/php-registration-form.git
```

2. **Move the folder** into your server directory (`htdocs` or `www`)

3. **Open in browser**

```
http://localhost/php-registration-form/
```

**Or use PHP built-in server:**

```bash
cd php-registration-form
php -S localhost:8000
```

Then open → [http://localhost:8000](http://localhost:8000)
